# Demo video for Elgato review

Elgato asked for a short video showing the plugin working, sent to maker@elgato.com before approval. Aim for 1 to 2 minutes, no editing needed.

## Set-up before recording

- Record with OBS at 1920 × 1080. Put the Stream Deck app on one side of the screen and your Twitch chat (pop-out chat) on the other.
- If you can, add a phone or webcam shot of the physical Stream Deck in a corner, so reviewers see a real key light up.
- Have a second Twitch account logged in somewhere (another browser or a phone) to type commands as a viewer. Your own account works too, since the broadcaster always passes the permission check.
- Make an action that's easy to see and hear: a multi-action that switches an OBS scene or plays a sound. Put it on the MCP Deck.
- Sign out of the plugin first (Status key settings, Sign out), so the sign-in can be shown.
- Turn off any notifications or windows showing private information.

## Shots

1. **Requirements (10 s).** Stream Deck preferences with **Enable MCP Actions** turned on, then the MCP Deck with your action on it.
2. **Sign in (20 s).** Press the Status key. Twitch's activation page opens in your browser, and the code shows on the key and in its settings. Approve it on Twitch, then show the Status key turning green with your channel name.
3. **Set up a trigger (20 s).** Drag a Trigger key onto a page. Type `!demo` as the command, pick your action, tick Everyone, and set a cooldown of 10 s.
4. **Test press (5 s).** Press the key on the device: the action runs.
5. **From chat (15 s).** From the viewer account, type `!demo` in chat. The key lights up yellow and the action runs.
6. **Cooldown (10 s).** Type `!demo` again straight away. Nothing happens. Wait out the cooldown, type it again, and it runs.
7. **Turn it off (10 s).** Hold the key until it shows Off, type `!demo` in chat, and nothing happens. Hold it again to turn it back on.
8. **Only real commands count (optional, 10 s).** Type `has anyone tried !demo` and `!demoxyz`. Neither runs anything, because the command has to be the first word of the message. Then type `!demo with extra words`: it runs the same action as before, since nothing else from the message is used.

Narration or captions are optional. A sentence of text at the start ("Chat Triggers for Twitch 1.0.0, Windows 11, Stream Deck 7.4") helps.

## Sending it

Reply to Elgato's rejection email so it stays in the same thread. Attach the video if it's small enough (most email services stop at 20 to 25 MB). Otherwise upload it as an unlisted YouTube video or a shared Google Drive file and include the link.

The same recording, trimmed to the chat and key shots, can also go in the Marketplace gallery as an MP4 (1920 × 1080, under 250 MB).
