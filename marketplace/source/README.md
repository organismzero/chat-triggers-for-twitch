# Source images

## stream-deck-mk2.png

Elgato's official product render of the Stream Deck MK.2, used for the Marketplace thumbnail so the device is shown accurately, as Elgato's product guidelines ask.

- **From:** the Stream Deck MK.2 media kit, linked from the [Elgato Media Room](https://www.elgato.com/s/media-room): <https://keystone.corsair.com/en/Stream_Deck_MK_2/press-kit/>, section "Device Shot (PNG)".
- **Original file:** `Stream_Deck_MK.2_Device_Shot_02_No Cable_Shadow` (6000 × 4000 PNG): <https://res.cloudinary.com/corsairdam/image/upload/v1774609007/Stream_Deck_MK.2_Device_Shot_02_No_Cable_Shadow_u0zfei.png>
- **Changes:** cropped to the device and scaled to 1200 × 763. The device itself isn't altered. `npm run marketplace` draws the plugin's own key images over the key screens.
- **Downloaded:** 12 November 2026.

The media kit didn't state any usage terms. Elgato's [product guidelines](https://docs.elgato.com/guidelines/products#gallery) point makers to the Media Room for official device images.
